## 💡 **Root Cause Analysis**

### **Why This Happened:**

1. ✅ Created `SoftwareTestingTraining.tsx` with complete content
2. ✅ Copied it as template for other courses (for layout consistency)
3. ❌ **FORGOT** to update component names
4. ❌ **FORGOT** to update page titles and breadcrumbs
5. ❌ **FORGOT** to update course descriptions
6. ❌ **FORGOT** to update export statements
7. ❌ Pages went live with wrong content

### **Lesson Learned:**
When using templates, create a proper template component with props or create a checklist to ensure all content is updated.
